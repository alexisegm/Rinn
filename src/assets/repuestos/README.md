# Imágenes de repuestos

Sube aquí las imágenes reales de cada repuesto.

Buenas prácticas:
- usa nombres claros y consistentes, por ejemplo: `sku-001.png`
- conserva el mismo formato para facilitar el reemplazo posterior
- mantiene una imagen por cada producto cuando tengas el catálogo completo

Puedes referenciar una imagen desde el código usando `resolveRepuestoImage('sku-001.png')`.
